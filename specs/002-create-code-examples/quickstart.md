# Quickstart: Running the Code Examples

This guide explains how to set up and run the video code examples.

## Prerequisites
- Node.js and npm installed on your system.

## Steps

1.  **Navigate to the project directory**:
    Open your terminal and change into the `video-examples` directory:
    ```bash
    cd video-examples
    ```

2.  **Install dependencies**:
    Run the following command to install the necessary packages:
    ```bash
    npm install
    ```

3.  **Start the development server**:
    Execute the following command to start the Vite development server:
    ```bash
    npm run dev
    ```

4.  **View the examples**:
    Open your web browser and navigate to the URL provided by Vite (usually `http://localhost:5173`). You will see the running application with the ability to switch between the different chart examples.
